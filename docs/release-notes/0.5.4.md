# SkillDock v0.5.4

发布日期：2026-10-04
递交范围：v0.5.3...v0.5.4

### 发布概览

本次更新修复批量简介请求的并发问题，并优化 GitHub 仓库技能结果列表的滚动布局。

### 用户可见更新

- **批量简介生成**：逐项串行发送模型请求，同时保留每项完成后的即时反馈，降低并发连接失败风险。
- **GitHub 仓库结果列表**：仓库页面固定在窗口内，长技能列表在独立区域滚动。

### 如何选择下载文件

| 文件 | 适用场景 |
|---|---|
| `SkillDock_0.5.4_x64-setup.exe` | Windows 10/11 x64 普通用户，默认推荐（自动处理 WebView2 依赖） |
| `SkillDock-0.5.4-x64-green.zip` | Windows 免安装便携版，解压即用 |
| `SkillDock_0.5.4_x64.dmg` | macOS Intel 机型 |
| `SkillDock_0.5.4_aarch64.dmg` | macOS Apple Silicon（M 系列）机型 |

### 系统要求

- **Windows**：Windows 10 / 11 x64；安装版在需要时自动处理 WebView2 依赖。
- **macOS**：macOS 12 (Monterey) 及以上；当前构建未签名，首次启动需右键选择「打开」。

### 开发者变更

- 版本号同步更新至 0.5.4：`package.json`、`package-lock.json`、`tauri.conf.json`、`Cargo.toml`、`Cargo.lock`；浏览器预览版本兜底值同步更新。
- 推送 `v0.5.4` 标签会触发 GitHub Actions 构建 Windows x64 与 macOS x64 / Apple Silicon 安装资源，并自动发布 GitHub Release。

### 已知限制

- 此版本发布资产面向 Windows x64 和 macOS Intel / Apple Silicon；当前 Release 工作流不生成 Linux 安装包。
- macOS 应用尚未签名或公证。
