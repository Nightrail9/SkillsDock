## SkillDock (技能坞) v0.3.1

发布日期：2026-09-22
递交范围：v0.3.0...v0.3.1

### 发布概览

本次发布聚焦「Windows 之外的平台也能真正可用」：对 macOS / Linux 的使用路径做了逐项核查，修复了 4 个真实跨平台缺陷；同时修复了设置→AI 工具页的开关频闪与顶栏页签间距问题，并把关于页错误显示的版本号(此前恒为 v1.2.0)改为运行时读取真实版本。

### 用户可见更新

- **macOS 项目路径显示修复**：此前在 macOS 上添加项目目录后，路径会被解析成 `/System/Volumes/Data/Users/...`(firmlink 真实路径)导致无法折叠为 `~/...`、界面显示超长绝对路径。现在非 Windows 平台只做绝对化、不解析符号链接，路径按用户视角保存与展示。
- **符号链接分发引导分平台**：macOS / Linux 原生支持符号链接、无需管理员权限。此前这两个平台也可能弹出 Windows 专属的「UAC 提权 / 开发者模式」引导，点击后无任何效果。现在非 Windows 平台探测到不支持符号链接时，自动回退为文件复制并明确提示；Windows 平台引导流程不变。
- **ZIP 安装兼容性修复**：由 Windows 工具生成、条目名使用反斜杠分隔(`repo-main\SKILL.md`)的 ZIP，在 macOS / Linux 上此前会被解压成单个文件导致安装失败；现已统一归一化条目名与符号链接目标的分隔符。
- **AI 工具页开关频闪修复**：此前启用/停用任一 AI 工具时，页面上所有工具的开关会一起变半透明再恢复(全局忙碌状态所致)。现在每个开关的忙碌状态只跟随自己的操作，切换时其它开关完全不受影响。
- **顶栏页签间距修复**：导航页签块内相邻页签此前零间隙紧贴(活动页签的白色底块会贴住相邻页签)，现在页签之间有明确间距；顶栏三个区域(品牌 / 导航 / 窗口按钮)的兜底最小间距同步加大，窄窗口下也不会相互贴近。
- **关于页版本号修正**：此前恒显示 `v1.2.0`，与真实版本完全不符；现在从安装包信息运行时读取。

### 系统要求

- **Windows**: Windows 10 / 11 (x64)，运行时自动下载 WebView2
- **macOS**: macOS 12 (Monterey) 及以上，Intel 或 Apple Silicon；未购买代码签名证书，首次打开需右键「打开」
- **Linux**: 在 Ubuntu 26.04 上构建（依赖 WebKit2GTK 4.1 与 GTK3，各包格式均已声明依赖）；实测主程序最高仅需 glibc 2.39 符号，适用于 Ubuntu 24.04+、Debian 13+、Fedora 40+ 等较新发行版；x86_64 / aarch64

### 开发者变更

- 跨平台核查与修复：
  - `commands/mod.rs`：`add_skill_project` 按平台分流路径规范化（Windows 保留 canonicalize 以统一盘符大小写；非 Windows 仅绝对化，规避 macOS firmlink）
  - `services/skill_service.rs`：ZIP 条目名与链接目标统一归一化反斜杠分隔符
  - `commands/mod.rs`：`restart_as_admin` 非 Windows 分支返回明确错误而非静默成功
  - `components/SettingsView.tsx`：分发方式切换按平台分流；符号链接说明文案分平台
  - 新增 `lib/utils/platform.ts` 平台识别工具
- 版本号升级至 0.3.1：`package.json` / `package-lock.json` / `tauri.conf.json` / `Cargo.toml` 四处同步；关于页改为运行时 `getVersion()`
- `tauri.conf.json` 新增 `bundle.macOS.minimumSystemVersion = 12.0`，与文档承诺的 macOS 12+ 对齐
- `.github/workflows/release-macos.yml`：版本号从 `tauri.conf.json` 动态读取，不再硬编码，后续发版不会再出现"资产名与版本不符"
- mock 运行时命令名与后端对齐(`toggle_tool_enabled`)，浏览器预览的开关切换恢复可用

### 已知限制

- macOS / Linux 构建产物分别在 macOS  runner 与 Linux Docker 环境中产出，未经本机实机安装验证；核心逻辑路径(主目录、默认技能目录、分发与扫描)已完成代码级跨平台核查
- Linux 应用数据仍位于 `~/.skilldock/`(未采用 XDG `~/.local/share`)，为保持三平台数据库路径一致的设计取舍
