# SkillDock v0.5.3

发布日期：2026-10-03
递交范围：v0.5.2...v0.5.3

### 发布概览

本次更新优化已安装技能筛选和 GitHub 仓库安装流程。

### 用户可见更新

- **作用范围筛选**：再次点击已选中的全局或项目范围，即可取消该筛选。
- **GitHub 仓库多选安装**：探测仓库后可逐项勾选、全选或取消全选，并仅安装选中的未安装技能。
- **继续安装体验**：安装成功后留在发现页，便于继续从当前 GitHub 仓库选择其他技能。

### 如何选择下载文件

| 文件 | 适用场景 |
|---|---|
| `SkillDock_0.5.3_x64-setup.exe` | Windows 10/11 x64 普通用户，默认推荐（自动处理 WebView2 依赖） |
| `SkillDock-0.5.3-x64-green.zip` | Windows 免安装便携版，解压即用 |
| `SkillDock_0.5.3_x64.dmg` | macOS Intel 机型 |
| `SkillDock_0.5.3_aarch64.dmg` | macOS Apple Silicon（M 系列）机型 |

### 系统要求

- **Windows**：Windows 10 / 11 x64；安装版在需要时自动处理 WebView2 依赖。
- **macOS**：macOS 12 (Monterey) 及以上；当前构建未签名，首次启动需右键选择「打开」。

### 开发者变更

- 版本号同步更新至 0.5.3：`package.json`、`package-lock.json`、`tauri.conf.json`、`Cargo.toml`、`Cargo.lock`；浏览器预览版本兜底值同步更新。
- 推送 `v0.5.3` 标签会触发 GitHub Actions 构建 Windows x64 与 macOS x64 / Apple Silicon 安装资源，并自动发布 GitHub Release。

### 已知限制

- 此版本发布资产面向 Windows x64 和 macOS Intel / Apple Silicon；当前 Release 工作流不生成 Linux 安装包。
- macOS 应用尚未签名或公证。
