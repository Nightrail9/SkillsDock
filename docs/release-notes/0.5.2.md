# SkillDock v0.5.2

发布日期：2026-10-03
递交范围：v0.5.1...v0.5.2

### 发布概览

本次更新改进待调度技能的分发目标，提供批量操作的逐项反馈，并优化本地导入技能的上游来源识别。

### 用户可见更新

- **待调度技能分发范围**：可将选中的待调度技能分发到全局或单个项目；全局分发会清除项目关联，保持作用域互斥。
- **批量简介生成反馈**：每个技能的简介生成完成后立即显示成功或失败结果，并刷新该技能状态。
- **批量更新反馈**：逐项显示更新结果，不必等整批结束才看到进度；磁盘分发保持串行，避免并发覆盖工具目录。
- **上游来源识别**：本地导入时优先匹配 skills.sh 中的原作者仓库，避免在匹配成功时把用户维护的 GitHub 镜像当作技能上游。

### 如何选择下载文件

| 文件 | 适用场景 |
|---|---|
| `SkillDock_0.5.2_x64-setup.exe` | Windows 10/11 x64 普通用户，默认推荐（自动处理 WebView2 依赖） |
| `SkillDock-0.5.2-x64-green.zip` | Windows 免安装便携版，解压即用 |
| `SkillDock_0.5.2_x64.dmg` | macOS Intel 机型 |
| `SkillDock_0.5.2_aarch64.dmg` | macOS Apple Silicon（M 系列）机型 |

### 系统要求

- **Windows**：Windows 10 / 11 x64；安装版在需要时自动处理 WebView2 依赖。
- **macOS**：macOS 12 (Monterey) 及以上；当前构建未签名，首次启动需右键选择「打开」。

### 开发者变更

- 版本号同步更新至 0.5.2：`package.json`、`package-lock.json`、`tauri.conf.json`、`Cargo.toml`、`Cargo.lock`；浏览器预览版本兜底值同步更新。
- 推送 `v0.5.2` 标签会触发 GitHub Actions 构建 Windows x64 与 macOS x64 / Apple Silicon 安装资源，并自动发布 GitHub Release。

### 已知限制

- 此版本发布资产面向 Windows x64 和 macOS Intel / Apple Silicon；当前 Release 工作流不生成 Linux 安装包。
- macOS 应用尚未签名或公证。
