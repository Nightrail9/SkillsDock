# SkillDock v0.5.0

发布日期：2026-10-03
递交范围：v0.4.2...v0.5.0

### 发布概览

本次发布增强项目级技能管理：同一技能可关联多个项目，仍集中存储一份并分发至各项目；同时完善项目管理界面、设置页本地化与键盘/辅助技术支持，并改进技能筛选和待调度流程。

### 用户可见更新

- **技能跨项目复用**：将已纳管的项目技能分配给多个项目；技能内容集中保存在中央技能库，部署状态按项目维护。
- **项目技能管理**：项目页支持查看、分配和移除技能，扫描项目目录中的现有技能并纳入管理；移除项目前显示相关技能数量和处理选项。
- **设置页本地化与可访问性**：补齐英文设置文案；语言、主题和分发方式可用键盘操作，设置项和工具开关提供辅助技术可读的名称与状态。
- **技能筛选与调度改进**：多选标签按同时满足筛选；全局可用列表不再包含尚未分发的技能；待调度流程支持标签筛选与工具卡片选择，每次选择一个目标项目，采用下拉框并移除分发预览；全局技能卡片不再显示“全局技能”标记。

### 如何选择下载文件

| 文件 | 适用场景 |
|---|---|
| `SkillDock_0.5.0_x64-setup.exe` | Windows 10/11 x64 普通用户，默认推荐（自动处理 WebView2 依赖） |
| `SkillDock-0.5.0-x64-green.zip` | Windows 免安装便携版，解压即用 |
| `SkillDock_0.5.0_x64.dmg` | macOS Intel 机型 |
| `SkillDock_0.5.0_aarch64.dmg` | macOS Apple Silicon（M 系列）机型 |

### 系统要求

- **Windows**：Windows 10 / 11 x64；安装版在需要时自动处理 WebView2 依赖。
- **macOS**：macOS 12 (Monterey) 及以上；当前构建未签名，首次启动需右键选择「打开」。

### 开发者变更

- 项目技能关联改为多对多关系；数据库初始化时将既有项目技能回填到关联表。
- 版本号同步更新至 0.5.0：`package.json`、`package-lock.json`、`tauri.conf.json`、`Cargo.toml`、`Cargo.lock`；浏览器预览版本兜底值同步更新。
- GitHub Release 工作流为 Windows 构建 NSIS 安装包和便携 ZIP，并为 macOS x64 与 aarch64 构建 DMG 及更新签名文件。
- 已重新上传 v0.5.0 的 `latest.json`，Windows 自动更新资产改用公开下载直链以修复 403。

### 已知限制

- 此版本发布资产面向 Windows x64 和 macOS Intel / Apple Silicon；当前 Release 工作流不生成 Linux 安装包。
- macOS 应用尚未签名或公证。
