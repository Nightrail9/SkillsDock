# SkillDock v0.5.1

发布日期：2026-10-03
递交范围：v0.5.0...v0.5.1

### 发布概览

本次发布修复应用内更新下载返回 403 的问题，并简化待调度技能的项目选择流程。

### 用户可见更新

- **应用自动更新修复**：更新清单中的安装包地址改为公开下载直链，修复从旧版本下载更新时返回 403 的问题。
- **待调度流程调整**：每次仅选择一个目标项目；项目改用下拉框，项目与 AI 工具选择纵向排列；移除分发预览。全局技能卡片不再显示“全局技能”标记。

### 如何选择下载文件

| 文件 | 适用场景 |
|---|---|
| `SkillDock_0.5.1_x64-setup.exe` | Windows 10/11 x64 普通用户，默认推荐（自动处理 WebView2 依赖） |
| `SkillDock-0.5.1-x64-green.zip` | Windows 免安装便携版，解压即用 |
| `SkillDock_0.5.1_x64.dmg` | macOS Intel 机型 |
| `SkillDock_0.5.1_aarch64.dmg` | macOS Apple Silicon（M 系列）机型 |

### 系统要求

- **Windows**：Windows 10 / 11 x64；安装版在需要时自动处理 WebView2 依赖。
- **macOS**：macOS 12 (Monterey) 及以上；当前构建未签名，首次启动需右键选择「打开」。

### 开发者变更

- 版本号同步更新至 0.5.1：`package.json`、`package-lock.json`、`tauri.conf.json`、`Cargo.toml`、`Cargo.lock`；浏览器预览版本兜底值同步更新。
- GitHub Release 工作流在发布完成前将更新清单中的 GitHub API 资产地址映射为公开下载直链。

### 已知限制

- 此版本发布资产面向 Windows x64 和 macOS Intel / Apple Silicon；当前 Release 工作流不生成 Linux 安装包。
- macOS 应用尚未签名或公证。
