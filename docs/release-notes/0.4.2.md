# SkillDock v0.4.2

发布日期：2026-10-01
递交范围：v0.4.1...v0.4.2

### 发布概览

本次发布修复存量技能导入时工具启用范围错误的问题，并补充应用更新检查在无可用更新时的明确反馈。

### 用户可见更新

- **存量技能分发状态修复**：导入时按每项技能实际发现的 AI 工具记录分发状态，避免把某个工具未发现的技能也标记为已启用。
- **应用更新检查反馈**：检查结果为当前已是最新版本时，在设置页的应用更新区域显示状态提示。

### 如何选择下载文件

| 文件 | 适用场景 |
|---|---|
| `SkillDock_0.4.2_x64-setup.exe` | Windows 10/11 普通用户，默认推荐（自动处理 WebView2 依赖） |
| `SkillDock-0.4.2-x64-green.zip` | Windows 免安装便携版，解压即用，适合无管理员权限或不愿安装的环境 |
| `SkillDock_0.4.2_x64.dmg` | macOS Intel 机型 |
| `SkillDock_0.4.2_aarch64.dmg` | macOS Apple Silicon（M 系列）机型 |

### 系统要求

- **Windows**：Windows 10 / 11 x64；安装版在需要时自动处理 WebView2 依赖
- **macOS**：macOS 12 (Monterey) 及以上，Intel 或 Apple Silicon；未签名版本首次启动需右键「打开」

### 开发者与构建更新

- 版本号升级至 0.4.2，并在五处配置文件同步更新：`package.json`、`package-lock.json`、`tauri.conf.json`、`Cargo.toml` 与 `Cargo.lock`
- 关于页浏览器预览的版本兜底值同步为 0.4.2
- Windows 安装包使用 NSIS 构建；macOS x64 与 aarch64 DMG 由 `.github/workflows/release-macos.yml` 构建
- Windows 便携 ZIP 包含 `SkillDock.exe` 与 `skilldock-portable.flag`
