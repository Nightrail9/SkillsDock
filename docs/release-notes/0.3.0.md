## SkillDock (技能坞) v0.3.0

发布日期：2026-09-22
递交范围：v0.2.0...v0.3.0

### 发布概览

弹窗在小窗口与低分辨率下不再溢出屏幕，误触关闭被消除；安装包从「Windows 单包」扩展为 Windows / macOS / Linux 三大平台共 13 个资产，macOS 与 Linux（含 ARM64）首次获得官方构建。

### 用户可见更新

- **弹窗布局修复**：安装、分享、标签编辑、卸载对话、添加自定义工具等 6 个弹窗统一改为「标题与操作按钮固定、正文区内部滚动」。此前在 1440×900 以下的小窗口或低分辨率屏幕上，弹窗内容会超出屏幕、底部按钮被顶出不可见，现在任何窗口尺寸下按钮始终可见。
- **移除遮罩层点击关闭**：上述弹窗不再支持点击半透明遮罩关闭，避免滚动正文或拖拽时误触导致弹窗意外关闭；统一由右上角关闭按钮或明确的操作按钮关闭。
- **引导弹窗步骤按钮固定**：新手引导的「上一步/下一步」不再被步骤内容顶出屏幕。
- **安装包矩阵扩充**：
  - Windows 新增 MSI 安装包（企业批量部署 / GPO 场景）
  - 新增 macOS dmg（Intel 与 Apple Silicon 双架构）
  - 新增 Linux deb / rpm / AppImage（x86_64 与 aarch64 双架构）
  - 保留 Windows 绿色便携版 zip

### 系统要求

- **Windows**：Windows 10 / 11 x64；Microsoft Edge WebView2 运行时（Win10/11 通常自带，安装版缺失时会自动下载）
- **macOS**：macOS 12 (Monterey) 及以上，Intel 或 Apple Silicon；未购买代码签名证书，首次打开需右键「打开」
- **Linux**：在 Ubuntu 26.04 上构建（依赖 WebKit2GTK 4.1 与 GTK3，各包格式均已声明依赖）；实测主程序最高仅需 glibc 2.39 符号，适用于 Ubuntu 24.04+、Debian 13+、Fedora 40+ 等较新发行版；x86_64 / aarch64

### 开发者与构建更新

- `bundle.targets` 由仅 `nsis` 扩展为 `nsis / msi / dmg / app / deb / rpm / appimage` 六平台目标，Tauri CLI 自动下载缓存 WiX/NSIS 打包工具
- 新增 `src-tauri/docker/`（Dockerfile + build.sh）：Linux 双架构打包方案，同时支持 Docker 容器与 WSL2 原生/交叉构建（aarch64 通过 `aarch64-linux-gnu-gcc` 交叉工具链 + arm64 多架构依赖完成）
- 新增 `.github/workflows/release-macos.yml`：推送 `v*` 标签时由 GitHub Actions macOS runner 构建双架构 dmg / app.tar.gz
- 版本号三处同步 0.3.0（`package.json` / `tauri.conf.json` / `Cargo.toml`），并修正 `package-lock.json` 根版本号滞后问题
- 工作区 6 个前端组件弹窗布局修复（见「用户可见更新」）

### 常见问题

- **Windows 提示「已保护你的电脑」**：点击「更多信息」→「仍要运行」。软件暂未购买代码签名证书，属正常现象。
- **macOS 提示「无法验证开发者」**：首次打开请右键（或按住 Control 点击）应用图标→「打开」，在弹出确认中再次点击「打开」。
- **数据位置**：`~/.skilldock/`（数据库、中央技能库、技能文件），删除该文件夹即完全卸载。
- **LLM 简介生成**：设置页填写 OpenAI 兼容接口（Base URL / 模型 / API Key）后即可使用；API Key 仅保存在本机客户端。

## English Release Notes

### SkillDock v0.3.0

Release date: 2026-09-22
Commit range: v0.2.0...v0.3.0

### Release Overview

Dialogs no longer overflow the screen on small windows and low-resolution displays, and accidental dismissals are gone. The release assets grow from a single Windows installer to 13 assets across Windows, macOS, and Linux — macOS and Linux (including ARM64) get official builds for the first time.

### User-Facing

- **Dialog layout fixes**: the 6 dialogs (install, share, tag edit, uninstall, add custom tool, onboarding) now pin the header and action buttons and scroll only the body. On screens smaller than 1440×900, content used to overflow the screen and push the bottom buttons out of view; buttons now stay reachable at any window size.
- **Removed click-on-backdrop dismiss**: clicking the semi-transparent backdrop no longer closes those dialogs, preventing accidental dismissal while scrolling the body or dragging. Close via the × button or an explicit action instead.
- **Onboarding stepper pinned**: the Back/Next buttons are no longer pushed off-screen by step content.
- **Expanded asset matrix**:
  - Windows gains an MSI installer (enterprise deployment / GPO)
  - New macOS dmg builds for Intel and Apple Silicon
  - New Linux deb / rpm / AppImage builds for x86_64 and aarch64
  - The Windows portable (green) zip is retained

### Choosing a Download

See the table above — one row per asset with the recommended system and audience: ordinary users take the `.exe` or `.dmg`; enterprise deployment uses the MSI; restricted users use the portable zip; Linux users pick deb/rpm for their distribution or the AppImage for anything else.

### System Requirements

- **Windows**: Windows 10 / 11 x64; Microsoft Edge WebView2 runtime (usually preinstalled on Win10/11; the NSIS installer fetches it when missing)
- **macOS**: macOS 12 (Monterey) or later, Intel or Apple Silicon. The build is unsigned (no paid certificate yet) — right-click → Open on first launch.
- **Linux**: built on Ubuntu 26.04 (requires WebKit2GTK 4.1 and GTK3, declared by each package format); the binaries need glibc symbols no newer than 2.39, so they run on Ubuntu 24.04+, Debian 13+, Fedora 40+ and other recent distributions; x86_64 / aarch64

### Developer & Build

- `bundle.targets` extended from `nsis` alone to `nsis / msi / dmg / app / deb / rpm / appimage`; the Tauri CLI auto-downloads and caches the WiX/NSIS toolchains
- New `src-tauri/docker/` (Dockerfile + build.sh): the Linux dual-architecture packaging pipeline, usable both inside Docker and as a native/cross build under WSL2 (aarch64 via the `aarch64-linux-gnu-gcc` cross toolchain plus arm64 multiarch dependencies)
- New `.github/workflows/release-macos.yml`: pushes of `v*` tags trigger dual-architecture dmg / app.tar.gz builds on GitHub Actions macOS runners
- Version synced to 0.3.0 in `package.json` / `tauri.conf.json` / `Cargo.toml`; also fixed the stale root version in `package-lock.json`
- Dialog layout fixes across 6 frontend components (see User-Facing)

### FAQ

- **Windows SmartScreen warning**: click "More info" → "Run anyway". No code-signing certificate yet — this is expected.
- **macOS "developer cannot be verified"**: first launch — right-click (or Control-click) the app and choose "Open", then confirm again.
- **Data location**: `~/.skilldock/` (database, central skill library, skill files); deleting that folder fully removes the app's data.
- **LLM summaries**: fill in an OpenAI-compatible endpoint (Base URL / model / API key) in Settings; the key is stored locally in the client only.
